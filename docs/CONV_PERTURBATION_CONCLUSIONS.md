# Conv 扰动实验结论

## 1. 基线与控制变量

三折冻结模型基线完整复现：Acc `74.70 ± 0.70`、Recall `71.85 ± 1.82`、F1 `72.80 ± 1.22`。实验没有重新切窗、没有改变标签、没有重训模型；始终使用连续 5 秒、50% 重叠、整窗标签恒定、原三折测试索引和原 L1/L2 双层合并规则。

Conv1d 只有一层、卷积核为 3 个 10-ms 点，因此直接感受野为 30 ms。按照用户要求，扰动范围仍是显著点前后各 1 秒的合并区域；这相当于在关键行为附近同时破坏许多 30-ms 局部模式，而 5 秒窗的其余部分保持不变。

## 2. 四类方案结果

### 局部相位随机化

- L1：Acc 下降 0.75 个百分点，F1 下降 0.77，是相位方案中最明显的总体损失。
- L4：Acc 下降 0.51，F1 下降 0.42。
- L5：Acc 下降 0.36，F1 下降 0.30；真实类别概率下降 0.77 个百分点。
- L2：Acc/F1基本不降，但真实类别概率下降 0.47、logit margin 下降 0.092，说明分类边界的置信度已经减弱，只看准确率会漏掉这一变化。

相位随机化保留局部幅度谱，只破坏精确波形排列。因此该结果主要支持：L1、L4、L5相关窗口中的局部波形结构对模型有贡献。

### 多强度频谱匹配有色噪声

- `0.25σx–1.0σx`：整体影响很小，部分条件甚至略有改善，未形成稳定单调下降。
- `2.0σx`：L1的Acc下降1.39、Recall下降1.13、F1下降1.46，是全部Conv扰动中最明显的单项损失。
- `2.0σx`下L2的F1下降0.46，L4下降0.43。
- L5在`2.0σx`下准确率没有下降，但真实类别概率下降0.99、logit margin下降0.103，说明预测置信度降低而类别尚未翻转。

因此更准确的解释是：模型对低—中等局部噪声具有一定鲁棒性；只有达到较强噪声时，尤其L1相关窗口，局部模式才出现明显破坏。剂量效应并非所有标签都严格单调，不能简单写成“噪声越大性能必然越差”。

### 15–50 Hz局部高频消融

- L2：Acc下降0.66、F1下降0.59；Wrong Hole准确率下降2.02，Walking下降1.43，是高频消融中最清晰的结果。
- L4：Acc下降0.41、F1下降0.30。
- L5：Acc下降0.20、F1下降0.23。
- L1几乎不受影响。

本数据是100 Hz采样的神经计数序列，因此这里的15–50 Hz应解释为“快速时间变化”，不是传统EEG生理频带。结果提示Wrong Hole相关识别更依赖快速局部变化，而L1的有效局部信息不主要集中在该高频范围。

### 均值替换基线

- L4：Acc下降0.51、F1下降0.50。
- L5：Acc下降0.61、F1下降0.48。
- L2整体指标反而改善，但Walking类别下降1.32，提示不同类别间存在权衡。
- L1整体基本不变。

均值替换同时破坏幅值、波形、频率和变化率，只能作为强输入破坏基线。L4/L5在该方案下下降，说明其关键区域包含有用的动态信息；但不能据此判断究竟是幅值还是某个频率成分起作用。

## 3. 综合解释

当前较有依据的Conv相关结论为：

1. L1最依赖局部波形的稳定性：相位随机化和`2.0σx`强噪声均造成下降，尤其强噪声F1下降1.46。
2. L2更依赖快速时间变化：15–50 Hz消融导致最清晰的L2类别损失；相位扰动虽然未明显降低准确率，但降低了真实类别概率和logit margin。
3. L4对多种局部破坏均有中等幅度响应，包括相位、强噪声、高频消融和均值替换，方向较一致。
4. L5的准确率变化较小，但相位、强噪声和均值替换都会降低概率或部分合并类别准确率，说明其影响可能先表现为置信度下降。
5. L3三折总计只命中5个测试窗，任何看似不变或下降的结果都缺乏覆盖率，不能解释为L3不依赖Conv。

## 4. 必须保留的限制

- 三折命中窗总数不均衡：L1=36、L2=186、L3=5、L4=114、L5=167。不同L行的下降绝对值不能直接作为重要性排名。
- 当前只有3折，多数均值变化小于或接近折间标准差，应作为机制线索，而不是严格显著性结论。
- 这批结果使用的是完整模型，没有No-Conv冻结模型对照；因此可说明模型对Conv相关局部模式敏感，但不能证明效应完全由Conv单独产生。
- 目前按用户指定只扰动显著关键区。若要形成更强因果证据，还需要加入等长度随机区和非关键区对照，并证明关键区下降显著更大。
- 如果显著点表格使用了测试折数据进行筛选，会存在选择信息泄漏；正式论文应只用训练折确定关键点，再应用到对应测试折。
