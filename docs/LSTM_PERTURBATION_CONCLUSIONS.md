# LSTM 扰动实验结论

## 实验口径

- 所有输入仍是连续 5 秒（500 个 10 ms bin）、50% 重叠（步长 250 bin）、整窗标签恒定。
- 使用 `outputs_legacy` 的三折冻结模型与原始测试索引，不重新训练或微调。
- 显著点来自 `Summary_P_long` 中 `window_ms = 10`、`p_value < 0.05`、L1–L5、时间范围 `[-1, 1] s` 的记录；每个显著点扩展为前后各 1 秒并在原 5 秒窗边界裁剪。
- 输出完全沿用原 run1/run2 的 L1/L2 双层合并。基线复现为 Acc `74.70 ± 0.70`、Recall `71.85 ± 1.82`、F1 `72.80 ± 1.22`。

## 主要发现

1. **远距离等长片段交换给出了最清楚的序列顺序证据。** L1 扰动后 Acc/F1 分别下降约 0.65/0.53 个百分点，L2 下降约 0.62/0.48 个百分点。L2 对应结果中 Wrong Hole Exploration 的类别准确率下降约 1.70 个百分点，是所有主要类别变化中最明显的一项。
2. **块序打乱的影响较小，但在 L2、L4、L5 上较一致。** 不同块长下 F1 常见下降约 0.29–0.39 个百分点；100 ms 时 L4/L5 的 F1 均下降约 0.39，400 ms 时 L2 的 F1 下降约 0.39。块长与性能下降没有稳定的单调关系，说明证据更支持“局部时间顺序有用”，尚不能据此确定唯一的最优时间尺度。
3. **状态清零提示关键点之前的递归状态对部分行为有贡献。** L2 在关键段起点清零时 Acc/F1 约下降 0.29/0.22，Wrong Hole Exploration 下降约 0.75；L1 在关键段终点清零时 Acc/F1 约下降 0.46/0.39，并伴随 Changing Direction 约 1.08 的变化。由于最终指标经过双层合并，某一 L 标签行的变化不能简单等同为只影响同名最终类别。
4. **有效历史长度实验在约 200 ms 后基本收敛到基线。** 50–100 ms 条件只有极小波动；200 ms 时已接近基线，400/800 ms 在显示精度下与基线一致。这只说明“从关键点继续向后传递的 LSTM 隐状态路径”对更早历史不敏感，不能解释为整个网络只需要 200 ms，因为 Attention 仍可读取关键点之前已经生成的 LSTM 输出。
5. **Hesitating 可作为低覆盖/负对照观察，但 L3 只有 5 个受影响测试窗，不能作稳定推断。** L1/L2/L4/L5 的受影响测试窗约为 36/186/114/167，覆盖差异会直接影响扰动效应大小。

## 建议的论文表述

在保持原始 5 秒、50% 重叠和冻结三折模型不变的条件下，局部块序打乱与远距离片段交换造成小幅但有方向性的性能下降，其中远距离交换对 L1/L2 及 Wrong Hole Exploration 的影响最明显，提示模型利用了显著行为时段内的局部时间顺序。LSTM 状态清零进一步表明关键时段前后的递归状态传递对部分判别有贡献。有效历史实验在约 200 ms 后趋近基线，但由于 Attention 仍保留对较早 LSTM 输出的访问，该结果应限定为对“递归状态通路”的分析，而不是对整个模型有效历史长度的直接估计。

## 解释边界

- 效应总体小于三折间标准差，当前结果更适合解释为趋势证据，而不是强因果结论。
- 本轮未加入随机时点/非显著时点匹配对照，也没有替换为单独训练的 No-LSTM 模型，因此不能仅凭本实验断言效应完全由 LSTM 独占。
- 显著点表若由包含测试数据的全数据统计得到，存在解释层面的信息泄漏风险；正式论文建议在每个训练折内重新筛选显著点。
- 双层合并使某个 L 标签的扰动可能影响多个最终类别，应结合 Table 5 与 run1/run2 混淆矩阵共同解读。
