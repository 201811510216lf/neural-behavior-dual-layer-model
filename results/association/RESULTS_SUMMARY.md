# 严格 5 秒窗条件下的神经—类脑模型关联：五项实验结果

## 一、先给结论

这次结果与之前事件起点前后 1 秒或事件对齐重采样的结果不同：严格恢复“连续 5 秒、50% 重叠、整窗标签恒定、原三折、原双层合并”以后，模型基线精确回到 **Acc 74.70 ± 0.70%、Recall 71.85 ± 1.82%、F1 72.80 ± 1.22%**。

在这个可比基线上，确实可以找到神经信号与类脑模型之间的关联，但正确的表述不是“某一个显著时间点对应某一个模块”，而是：

> 模型从 Conv 到 LSTM、Attention，再到最终 Context，逐级把“与原始神经输入相似的表征几何”转换为“与行为分类更一致的决策几何”。

具体表现为：

- Conv 与真实神经输入几乎保持同一几何结构；
- LSTM 仍保留较强神经结构，但开始发生任务相关重组；
- Attention contribution 与原始神经几何的相似度进一步下降；
- 最终 Context 与原始神经几何最低，却与行为类别几何最高；
- 把学习到的 Attention 改成均匀平均后，Context 反而更像原始神经输入，但准确率从 74.70% 降至 44.95%。这说明“更像原始神经”不等于“更有分类价值”，学习到的 Attention 的作用正是选择性压缩和重组。

因此，原先输入端置零、最大值、最小值、平均值或围绕显著点扰动效果不稳定，并不代表模型和神经没有关系；更可能是因为这些操作破坏了输入分布，却没有对应模型内部真正使用的“表征几何”。

## 三、实验 2：神经—模型层表征 RSA / CKA

主分析采用 100 ms 聚合后的真实神经元数据；模型仍按训练时所需使用 12 通道补零输入。统计单位是记录，不把重叠窗口当成独立动物。

### Z-Euclidean RSA（均值，95% bootstrap CI）

| Run | Conv | LSTM | Attention contribution | Context |
|---|---:|---:|---:|---:|
| Run 1，n=19 | **0.975** [0.967, 0.981] | 0.839 [0.793, 0.880] | 0.445 [0.335, 0.550] | -0.006 [-0.134, 0.121] |
| Run 2，n=9 | **0.954** [0.917, 0.980] | 0.752 [0.530, 0.890] | 0.519 [0.316, 0.700] | 0.207 [0.045, 0.362] |

### Linear CKA（均值，95% bootstrap CI）

| Run | Conv | LSTM | Attention contribution | Context |
|---|---:|---:|---:|---:|
| Run 1，n=19 | **0.997** [0.995, 0.998] | 0.874 [0.852, 0.896] | 0.572 [0.509, 0.631] | 0.368 [0.294, 0.451] |
| Run 2，n=9 | **0.999** [0.998, 1.000] | 0.913 [0.878, 0.949] | 0.708 [0.614, 0.798] | 0.617 [0.526, 0.717] |

### 解释

这是一个非常清楚的“逐层转换梯度”：越靠近输入端越像原始神经信号，越靠近输出端越不再逐点复制原始输入。Conv 的高值本身不能证明独立神经机制，因为 Conv 直接由同一神经输入计算；真正有信息的是从 Conv → LSTM → Attention → Context 的系统性下降。

## 四、实验 3：与行为决策几何的对应

理想决策 RDM 定义为：同类窗口距离 0、异类窗口距离 1。

| Run | Neural | Conv | LSTM | Attention contribution | Context |
|---|---:|---:|---:|---:|---:|
| Run 1 | -0.002 | -0.010 | 0.036 | 0.004 | **0.342** [0.207, 0.466] |
| Run 2 | 0.021 | 0.060 | 0.108 | 0.058 | **0.225** [0.064, 0.394] |

控制原始神经 RDM 后，Context 的偏相关 RSA 仍为：

- Run 1：**0.331** [0.206, 0.449]
- Run 2：**0.218** [0.076, 0.377]

### 解释

原始神经窗口的总体几何并不会自动按行为类别聚类；网络在最终 Context 中建立了更接近分类目标的结构。也就是说，模型不是简单复制输入，而是在逐层形成任务相关表征。这比“把显著点置零后准确率下降多少”更能建立神经输入与类脑模块之间的桥梁。

## 五、实验 4：50% 重叠片段的一致性

相邻 5 秒窗共享完全相同的 2.5 秒原始数据。将这段完全相同的输入分别放在前一个窗尾部和后一个窗头部，比较模型表征。

| Run | 表征 | 共享 2.5 秒相似度 | 同标签非重叠对照 |
|---|---|---:|---:|
| Run 1 | Conv | 0.999 | 0.224 |
| Run 1 | LSTM | 0.979 | 0.321 |
| Run 1 | Attention contribution | 0.945 | 0.011 |
| Run 1 | Attention weights | 0.949 | 0.017 |
| Run 2 | Conv | 0.998 | 0.322 |
| Run 2 | LSTM | 0.963 | 0.240 |
| Run 2 | Attention contribution | 0.941 | 0.009 |
| Run 2 | Attention weights | 0.945 | 0.032 |

### 解释

- Conv 对相同局部输入几乎给出相同表示；
- LSTM 因窗口起点和前文不同出现轻微上下文依赖；
- Attention 仍高度识别相同片段，但其权重依赖整个 5 秒窗；
- 同标签但不共享原始样本的窗口相似度远低于共享片段。

这同时暴露了原随机三折的重要限制：测试窗中与某个训练窗共享原始样本的比例为：

| Run | Fold 1 | Fold 2 | Fold 3 |
|---|---:|---:|---:|
| Run 1 | 80.4% | 83.9% | 85.7% |
| Run 2 | 57.1% | 68.9% | 60.6% |

所以 74.70% 可以作为“原论文内部协议”的对照基线，但不能直接解释为严格的跨动物或完全独立时间段泛化性能。

## 六、实验 5：冻结完整模型的功能干预

由于本地只有完整模型的三折 checkpoint，没有 No-Conv、No-LSTM、No-Attention 的三折消融权重，本实验做的是同一模型的测试时干预，而不是重新训练的结构消融。

| 条件 | Acc (%) | Recall (%) | F1 (%) |
|---|---:|---:|---:|
| Full | **74.70 ± 0.70** | **71.85 ± 1.82** | **72.80 ± 1.22** |
| Zero Conv signal | 38.26 ± 7.41 | 33.33 ± 0.00 | 18.24 ± 2.80 |
| Zero LSTM signal | 39.19 ± 5.99 | 33.33 ± 0.00 | 18.53 ± 2.33 |
| Uniform Attention | 44.95 ± 12.21 | 42.60 ± 3.68 | 36.10 ± 8.24 |

Zero Conv 和 Zero LSTM 使 Context 的跨窗口方差接近 0，表征坍缩，因此其 Context—神经 RSA 没有定义，不能把少量数值波动解释为生物学对应。

均匀 Attention 的关键现象是：

- 准确率大幅下降约 29.75 个百分点；
- Run 1 的 Context—神经 RSA 从 -0.006 上升到 0.433；
- 但更接近原始神经几何并没有带来更好分类。

这说明学习到的 Attention 不是为了最大程度保留原始神经活动，而是为了保留对行为判别最有用的部分。

## 七、为什么之前的掩码和关键点扰动不理想

1. **原模型学习的是 5 秒整体模式，不是单个 t 检验显著点。** 单点显著性是边际统计结果，模型可能依赖跨神经元、跨时间的联合模式。
2. **置零、最大值、最小值会制造训练分布之外的数据。** 性能变化混合了“该信息重要”和“输入异常”两种原因。
3. **均值替换可能保留大量低频信息。** 看似掩码，实际上模型仍可从其余 4 秒或其他神经元恢复类别。
4. **50% 重叠造成信息冗余。** 同一关键片段可在相邻两个窗口出现，仅改一个窗口位置不一定消除证据。
5. **Attention 权重不是因果重要性分数。** 它与 LSTM 隐状态共同决定 Context，直接按显著点扰动输入和“消融 Attention 模块”不是同一层级的操作。
6. **真实神经元数不同。** 若把补零通道纳入神经统计，会把记录结构差异误当成神经效应；本项目已分开处理。

## 八、目前最稳妥的论文结论

可以写成：

> 在保持原始连续 5 秒、50% 重叠、整窗标签恒定及双层三折模型不变的条件下，神经—模型表征分析显示，模型内部存在从输入保真到任务抽象的逐层转换：Conv 和 LSTM 保留较强的神经输入几何，Attention 加权后相似性下降，而最终 Context 对行为类别结构的对应增强。测试时模块干预进一步表明，Conv、LSTM 和学习到的 Attention 均是原模型维持分类性能所必需的；其中均匀化 Attention 虽提高 Context 对原始神经几何的相似性，却显著降低分类性能，说明模型通过选择性重组而非简单复制神经信号形成行为判别表征。

同时必须注明：

- 这是同一神经输入驱动模型后的表征对应，不是独立脑区预测；
- 记录被当作动物/会话统计单位，目前没有更独立的 animal_id；
- 原随机三折存在重叠窗共享原始样本，不能替代后续按动物分组验证；
- 第 5 项是冻结模型的测试时干预，不是重新训练消融模型。
