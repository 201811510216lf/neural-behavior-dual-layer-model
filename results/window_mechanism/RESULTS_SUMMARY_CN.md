# 本轮时窗—结构—扰动实验结果

本目录包含根据《实验.md》补做的图 A–D、补充图 E、逐折源数据、统计表与完整复现代码；本地结果目录另有结构消融权重，但公开 GitHub 版本明确排除全部模型权重。所有性能变化均定义为“扰动后减基线”，单位为百分点（pp）；负值表示性能下降。

## 核心结果

- **L2 / Stage 2：** 最大值替换使 Stage-2 宏平均召回率平均下降 **3.63 ± 2.37 pp**。但同形状随机平移零分布的逐折单侧经验 p 值为 **0.968、0.996、0.832**，说明当前数据不能支持“原始 L2 时间位置比其他同形状位置更特殊”的结论。
- **L3 / Hesitating：** 最大值替换后的平均变化为 **+0.83 ± 1.44 pp**，但全部 legacy 窗口中只有 Run 1 的 2 个、Run 2 的 3 个中心点真正映射到 L3。Drop/Keep 结果因此主要反映覆盖极稀疏，不能据此认为 L3 无信息或具有充分性。
- **L5 / Walking：** 最大值替换使 Walking 召回率平均下降 **5.87 ± 3.51 pp**；注意力打乱和注意力置零分别变化 **−4.14 ± 7.29 pp** 与 **−2.51 ± 2.65 pp**。然而同形状随机平移的逐折 p 值为 **0.772、0.537、1.000**，同样不支持原始 L5 位置特异性。
- **结构 × 扰动交互：** 所有精确符号翻转检验经 BH-FDR 校正后均为 **q = 1.0**。由于只有 3 折，双侧精确 p 值理论最小只能达到 0.25；这些交互只能作为描述性趋势，不能写成确定的机制结论。

## 对原假设的修正

1. L2 和 L5 对最大值替换确实敏感，但随机零模型表明，敏感性可能来自替换量、掩码几何或广泛的模型脆弱性，而不一定来自选定时间点本身。
2. NoLSTM 或 NoAttention 在若干条件下反而比 Full 模型受损更大。例如 L2 最大值替换的 Full−NoLSTM 交互为 **+3.20 pp**，L5 最大值替换的 Full−NoAttention 为 **+3.51 pp**。这与“去掉该模块后时窗效应应消失”的简单预测不一致，更像是完整模块可能提供一定鲁棒性；但统计证据不足。
3. L3 的近零扰动效应首先应解释为映射覆盖不足，而不是“组间显著但行为无关”。

## 必须保留的限制

- legacy 协议采用 5 s 窗、2.5 s 步长和窗口级分层随机划分；训练与测试窗口可能共享原始时间样本，不能代表跨动物或跨会话泛化。
- legacy checkpoint 在 held-out fold 上选择最佳 epoch，因此绝对性能偏乐观。
- 本轮分析测量的是已拟合模型对输入扰动的敏感性，不是神经活动的生物学因果性。
- 原始逐时间点组间 p 值未做完整多重比较校正，不能与模型层面的决定性证据等同。

## 下一步最优先实验

重新按动物或独立记录划分训练/验证/测试集，并在不重叠窗口上复现 L2/L5 结果；随后使用事件对齐、预注册宽度的时窗和同形状置换检验。只有这一轮仍显示位置特异性，才适合把 L2/L5 写成论文的机制性主结果。
