# Selected two-group differences

These ten static figures are the behavior-aligned differences shown in the group-meeting presentation. Groups 1/2/4/6 were pooled and contrasted with groups 3/5.

The p values are exploratory time-point selections. They should not be interpreted as corrected confirmatory evidence. The pooled contrast mixes genotype, surgery, and treatment status; it therefore does not isolate an HIF3A effect.

No binned neural table, label file, animal-level value, or grouping spreadsheet is included here.
